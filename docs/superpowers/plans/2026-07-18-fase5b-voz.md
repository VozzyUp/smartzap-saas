# Fase 5B — Nota de voz no inbox — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`).

**Goal:** Gravar voz no inbox (tap grava / tap para → revisa → envia), remux para OGG/Opus com ffmpeg no servidor e enviar como nota de voz pelo número da conversa, reusando o pipeline da 5A. Fail-safe se o ffmpeg faltar.

**Architecture:** `apk add ffmpeg` no runtime; `remuxToOggOpus` (spawn ffmpeg em pipes) converte webm/opus→ogg/opus; a rota de mídia da 5A ganha um campo `voice`; `MessageInput` grava com MediaRecorder.

**Tech Stack:** Next.js 16, Node child_process, ffmpeg (Alpine), TypeScript, Vitest, React.

## Global Constraints

- Reusar o pipeline da 5A (`POST /api/inbox/conversations/[id]/media`, `uploadMediaToMeta`, `sendWhatsAppMedia`, `storeOutboundMedia`) — voz é variação de áudio.
- Envio pelo número da conversa (Fase 4). Remux em memória (pipes, sem arquivos temporários).
- Fail-safe: falha de remux/ffmpeg degrada para áudio comum, nunca perde a mensagem nem derruba a rota.
- Áudio ≤16MB validado antes do upload. `access_token` nunca ao client.
- Baseline: `tsc --noEmit` limpo, `npm run build` ok (o build NÃO exige ffmpeg — é runtime), `npx vitest run` sem regressão.
- Branch: `saas/fase-5b-voz` (já criada a partir de main c/ 5A mergeada).
- Agentes commitam com `git commit -m "..." -- <arquivos>`.

### Task 2: `lib/audio/voice-remux.ts`

**Files:** Create `lib/audio/voice-remux.ts` + `lib/audio/voice-remux.test.ts`.

**Interfaces:**
- Produces: `remuxToOggOpus(input: Buffer, inputMime: string): Promise<{ buffer: Buffer; mime: string; remuxed: boolean }>`.

- [ ] **Step 1: Testes falhando**

Mock `child_process.spawn` (via `vi.mock('child_process')`). Casos:
- input `audio/ogg` → retorna `{ remuxed:false, mime:'audio/ogg' }` sem chamar spawn.
- input `audio/webm` → chama `spawn('ffmpeg', [...,'-i','pipe:0','-c:a','libopus','-f','ogg','pipe:1'])`, escreve input no stdin, lê stdout → `{ buffer: <stdout>, mime:'audio/ogg', remuxed:true }`.
- spawn emite `error` ENOENT (ffmpeg ausente) → `{ buffer: input, mime: inputMime, remuxed:false }` (não lança).
- ffmpeg exit code ≠ 0 → degrada para input (remuxed:false), não lança.

- [ ] **Step 2: Rodar e ver falhar** — `npx vitest run lib/audio/voice-remux.test.ts`

- [ ] **Step 3: Implementar**

`spawn('ffmpeg', ['-hide_banner','-loglevel','error','-i','pipe:0','-c:a','libopus','-f','ogg','pipe:1'])`. Escrever `input` em `child.stdin` (end), acumular `child.stdout` em chunks, `child.on('error')` → degrada, `child.on('close', code)` → se `code===0` e há saída, resolve remuxed; senão degrada. Timeout (ex.: 15s) com `child.kill()` → degrada. NUNCA rejeitar (sempre resolve com o fallback). Guardar mime alvo `'audio/ogg'`.

- [ ] **Step 4: Rodar e ver passar** — `npx vitest run lib/audio/voice-remux.test.ts` + `npx tsc --noEmit`

- [ ] **Step 5: Commit**
```bash
git commit -m "feat(fase5b): remuxToOggOpus (ffmpeg pipes) com fail-safe" -- lib/audio/voice-remux.ts lib/audio/voice-remux.test.ts
```

### Task 4: UI — gravação no `MessageInput`

**Files:** Modify `components/features/inbox/MessageInput.tsx`.

- [ ] **Step 1: Gravação + preview + envio**

Ler o arquivo inteiro (a 5A já adicionou anexo/preview — siga o mesmo estilo/estado). Adicionar botão 🎤:
- Ao clicar: `navigator.mediaDevices.getUserMedia({ audio: true })` (negação → toast, aborta). Escolher mime: primeiro `audio/ogg;codecs=opus` se `MediaRecorder.isTypeSupported`, senão `audio/webm;codecs=opus`, senão default. Iniciar `MediaRecorder`, acumular chunks em `ondataavailable`.
- Durante: **timer** mm:ss (setInterval), botões **Parar** e **Cancelar**. Cancelar → `recorder.stop()` + descartar chunks + `stream.getTracks().forEach(t=>t.stop())`.
- Ao **Parar**: montar `Blob(chunks, { type })`, objectURL, mostrar **preview** `<audio controls>` + **Enviar**/**Cancelar**.
- Enviar: `FormData` com `file` (blob, filename `voice.ogg` se ogg senão `voice.webm`), `voice='true'`, `POST /api/inbox/conversations/${conversationId}/media`. Estado "enviando…". Sucesso → limpar tudo (a bolha vem via realtime). Erro → toast.
- Cleanup: revogar objectURL e parar tracks ao enviar/cancelar/desmontar (useEffect cleanup). Não quebrar texto nem o anexo de arquivo (5A).

- [ ] **Step 2: Verificar** — `npx tsc --noEmit` e `npm run build` (sem exigir ffmpeg).

- [ ] **Step 3: Commit**
