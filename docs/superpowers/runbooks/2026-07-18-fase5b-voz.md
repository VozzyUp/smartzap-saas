# Runbook — Fase 5B: Nota de voz no inbox (gravar + remux ffmpeg)

## O que foi entregue
- Gravação de **nota de voz** no inbox: no `MessageInput`, botão de microfone → grava (timer) → parar → **ouvir (preview)** → Enviar/Cancelar (estilo WhatsApp Web desktop).
- No servidor, o áudio é convertido para **OGG/Opus** (ffmpeg) e enviado como **nota de voz** (PTT) pelo número da conversa, reusando todo o pipeline de mídia da 5A.

## Arquitetura
- **ffmpeg no runtime:** `Dockerfile` (stage `runner`) faz `apk add --no-cache ffmpeg`. Só usado em runtime (o `next build` NÃO precisa de ffmpeg).
- **Remux:** `lib/audio/voice-remux.ts::remuxToOggOpus(buffer, mime)` roda `ffmpeg -i pipe:0 -c:a libopus -f ogg pipe:1` (stdin→stdout, sem arquivos temporários). Se já for `audio/ogg`, pula. **Fail-safe:** ffmpeg ausente/erro/timeout(15s) → devolve o buffer original sem lançar.
- **Envio:** `POST /api/inbox/conversations/[id]/media` ganhou o campo `voice`. Com `voice='true'` e áudio, remuxa antes de `uploadMediaToMeta`; valida tamanho (≤16MB) sobre o buffer **final**; envia como `audio/ogg` → a Meta renderiza como nota de voz.
- **Gravação:** `MediaRecorder` prefere `audio/ogg;codecs=opus` (Firefox), senão `audio/webm;codecs=opus` (Chrome).

## Infra / dependências
- **ffmpeg** é instalado na imagem pelo Dockerfile — nada a configurar manualmente. A imagem cresce ~alguns MB.
- Sem mudança de schema (reusa as colunas `media_*` da 5A). Sem novas variáveis de ambiente.

## Comportamento do fail-safe (importante — leia)
O remux só "degrada para áudio comum" quando o formato ORIGINAL já é aceito pela Cloud API da Meta:
- **Produção:** o ffmpeg está sempre presente (Dockerfile) → toda gravação vira `audio/ogg` e é enviada como **nota de voz**. ✅
- **Firefox:** grava direto em `audio/ogg` → funciona mesmo sem ffmpeg.
- **Chrome SEM ffmpeg (só em dev local):** grava `audio/webm`; sem ffmpeg o remux degrada para o webm original, que a Meta **não aceita** → o envio retorna **400** (o toast mostra o erro). Isso NÃO ocorre em produção (ffmpeg presente). Para testar voz no Chrome em dev, instale ffmpeg no PATH.

## Smoke test (pós-deploy)
1. **Chrome:** no inbox, 🎤 → gravar alguns segundos → parar → ouvir o preview → Enviar. No WhatsApp do cliente, chega como **nota de voz** (bolha de áudio PTT), enviada pelo número da conversa.
2. **Firefox:** idem (grava ogg direto).
3. **Cancelar:** iniciar gravação e cancelar → o microfone é liberado (sem ícone de "gravando" preso na aba), nada é enviado.
4. **Permissão negada:** negar o microfone → toast de erro, sem travar.
